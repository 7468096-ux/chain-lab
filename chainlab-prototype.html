What you will learn

Four ideas carry the whole technology. Each one has a hands-on step in the course.

SHA-256

Hashing

A fixed-length fingerprint of any data. Same input, same hash. One changed letter, a completely different hash.

prev → hash

Immutability

Each block stores the hash of the one before it. Edit an old block and every block after it breaks.

PoW · PoS

Consensus

Thousands of computers keep copies and agree on one history without trusting each other.

ERC-20 · ERC-721

Tokens

Coins, points and unique items like NFTs are entries in a smart contract that anyone can check.
